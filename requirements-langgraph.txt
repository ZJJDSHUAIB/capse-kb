# CAPSE 知识库 · 【可选】对照片的依赖 —— 主链不需要它

# ═══ ★★★ 这一份是给谁用的 ═══
#   只给 tools/agent_langgraph.py 用 —— 那是【对照片】,不是主链。
#
#       tools/agent.py            手写 if          ← 主链
#       tools/agent_graph.py      我写的执行器      ← 主链(零依赖)
#       tools/agent_langgraph.py  LangGraph 当执行器 ← ★ 只这一个需要本文件
#
# ★ 三个版本跑【同一批节点函数】,对照出来结构完全一样(6/6)。
#
# ═══ ⚠ 为什么单独一份,不并进 requirements.txt ═══
#   实测:langgraph 会拉【18 个包】,其中——
#       langchain-core   一个新的框架
#       langsmith        ★ 它是个可观测平台,【默认会把运行数据上报到云端】
#
#   ★★ 而这个项目一路的取舍是「少一个依赖,别人就少一步装包」
#      (见 requirements.txt 开头那段)。为了一个"换执行器"的对照,
#      拉 18 个包进去,那个取舍就白定了。
#   ★★★ 而且这里处理的是【报告原文】—— "数据出不出本机"不是小事。
#
# ═══ 那装了它,得到了什么 ═══
#   ★ 说实话:【在这段对话上,什么都没有】—— 三个执行器跑出来一样。
#   ★★ 它多给的三样,我们【一样都没用上】:
#        Checkpointer   每步存快照,能恢复、能时间旅行
#        并行           多个分支同时跑
#        中断           跑到一半停下等人
#   ★★★ 而它们的意义是【以后能加什么,以及加的时候不用动那七个节点】:
#        · Checkpointer → chat.py / serve.py 的会话【关掉就没了】,那是个真缺口
#        · 中断        → "这一步要不要你批准",人审该有的
#        · 并行        → 现在没有,但"同时查两个机场"是自然的
#
# ═══ 怎么装(只有想跑那个对照才需要) ═══
#   pip install -r requirements-langgraph.txt

langgraph==1.2.12
