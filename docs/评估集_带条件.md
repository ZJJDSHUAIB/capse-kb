```

· 「简称对应哪个机场」—— 我问的方式本身就在诱导挑一个
★★ 所以下面每道题都标了【我哪儿拿不准】。那些是真要你定的，不是客气。
```

## 五道题

### ① 最明显的——"如果…就…"摆在字面上

```
问题:   分析浦东近两期，如果降了就查原因，没降就看看它和同档平均水平比怎么样
期望:   先算出两期的分 → 判降没降 → ★ 只说它走到的那一支，不要两支都答
★ 实测(库里的真数):2025Q3=4.23、2025Q4=4.23 → 没降 → 该走"比同档"那一支
   ★★ 而你上次说这个答案该是【先给数、再给一张表】—— 那条规矩也要套在这里
⚠ 我拿不准:条件判完之后，要不要把"我判成了什么"写出来?
   ★ 我现在的做法是写（"我判成【不成立】，所以走这一支"）—— 对吧?
```

### ② 条件藏在字缝里——没有"如果"两个字

```
问题:   浦东2025Q4表现怎么样，要是不好就说说是哪一项拖后腿
期望:   ★ 先有一个"好不好"的判断，再决定要不要展开"哪一项"
⚠ 我拿不准:"不好"是谁定?—— 程序定（比如低于同档均值就算不好）、还是大模型定?
   ★ 而它要是定了"挺好"，那"哪一项拖后腿"就【不该答】—— 这个"不该答"你同意吗?
```

### ③ 要先算出来，才知道在说谁

```
问题:   浦东和虹桥2025Q4谁高，低的那家差在哪
期望:   ★ 先比出谁高（虹桥 4.25 > 浦东 4.23），再说【低的那家=浦东】差在哪
★ 这道题的坑:「低的那家」是个【代词】，而它指谁【得先算出来才知道】
   —— 句子里没有"如果"，可它照样是个岔路口
⚠ 我拿不准:"差在哪"要答到什么程度?—— 只说综合得分差 0.02，还是逐项比一张表?
```

### ④ ★★★ 反向题——问一个数，它【不该】走任何条件分支

```
问题:   浦东2025Q4综合得分是多少
期望:   一个数（4.23）+ 出处。★ 【就这些】—— 不许给表,不许展开,不许"顺便"
★★ 为什么要有这道:上面三道都是"该做条件"的,
   而【一个判据必须两个方向都验】—— 得有一道证明它【不会乱做条件】。
   ★★ 没有这道的话,一个"什么都当条件处理"的实现也能把上面三道蒙对。
```

### ⑤ 半道——它不是条件，是两步

```
问题:   浦东2025Q4排第几，前三名是谁
期望:   两件事都答:它的名次（第 5）+ 前三名的名单
★ 它不是"看情况"—— 两步【都必然要答】,没有岔路
⚠ 我拿不准:这道放在"带条件"这一组里【合不合适】——
   它的形状是"多步"而不是"分支"。
   ★ 我放进来是想看:实现会不会把"多步"和"分支"混成一回事。
```
