# 机场叫法表 —— 「人怎么称呼这些机场」

> **AI 起草，用户审。**（照「说法测试集」那个流程 —— 我写、你审。）
> ★ 这一份是 **第 20 课** 的另一半：**「用户说的话 → 库里的名字」**。

---

## 为什么单独一份

**第 20 课原本只想换掉一个正则**（`ask.py:1066` 的 `平均词`）。量了之后发现瓶颈不但在那儿：

```
6 句正向里【4 句根本没走到那条平均分支】—— 在更前面就被拦下了。
拦它们的是:【机场没认出来】。

  「上海浦东2025Q4和同档平均比怎么样」  → 认得出（「上海浦东」是库名的【前缀】）
  「浦东2025Q4比同一档的平均高多少」    → 认不出（「浦东」不是前缀）
```

**★★ 库里那个机场叫「上海浦东国际机场」,而人真正会说出口的名字是「浦东」。**

**★★★ 所以「浦东认不出」和「平均水平认不出」是同一件事：**
**把【用户的话】对到【库里的一个名字】上。**

## ★★★ 你定的那条判据（这是这一份的骨架）

> **「上海有两个机场 —— 你应该反问,是哪个机场呢?」**

**往下推一步 —— 而且是【查出来的】,不是推的:**

```
珠海金湾国际机场   只出现在 2023Q3
珠海金湾机场       2023Q3 没有，2024Q1 起都有     ← 期次【零重叠，刚好接上】
乌鲁木齐地窝堡     2023Q3 ~ 2024Q4
乌鲁木齐天山       2025Q1 ~ 2025Q4                ← 同上
（用户 2026-09-23 确认：这两组确实是【一个机场改过名】）
```

```
你说的:      一个说法对上【多个东西】 → 反问
★★ 往下推:   在【同一期里】对上多个   → 反问
   为什么:珠海那对全库看是 2 个，而【每一期里只有 1 个】
          → 要是反问"你说哪个珠海"，用户会觉得你在装傻
```

**★ 于是它是个四格的表:**

```
                一个东西              多个东西
 一个名字        ✅ 直接用             ★ 反问（上海、北京、成都）
 多个名字        ★ 合并（珠海、乌鲁木齐）  （同一期里不可能）
   0 个                                ★ 说找不到，不许猜
```

**★★ 左上/右下各踩一格,而它们归到同一条:【指不到唯一一个东西的时候,不许猜】。**

## ★★★ 量出来的一个判据：哪一半要向量，哪一半不用

**"通用后缀"这一层是【封闭的】—— 查得完，不用猜：**

```
44 个机场名，结尾【只有两种】：
    「国际机场」 43 个
    「机场」      1 个（珠海金湾机场）
```

**而"量名"那一侧是【开放的】：**

```
库里的字段名:得分 / 档位 / 行业平均 / 机场交通 / 机场安检 …
用户的说法:  均值 / 同档水平 / 普遍水平 / 同一档的 …

★★ 「均值」「同档水平」「普遍水平」和任何字段名【一个字都不共用】。
```

**★★★ 于是有一条判据：**

```
机场名这一侧   用户说的字 ⊂ 库里的名字（浦东 ⊂ 上海浦东国际机场）
               → ★ 子串能对上，不用语义；通用后缀只有 2 种，查得完

量名这一侧     用户说的字 ∩ 字段名 = 空（"均值" 和 "行业平均" 不共字）
               → ★ 必须语义
```

**★ 所以第 20 课不是"把一个正则换成向量"，是【两半各用各的办法】。**
**★★ 而这一条是量出来的，不是想出来的 —— 见上面那两组数。**
