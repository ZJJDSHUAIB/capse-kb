# 说法测试集 —— 「同一件事,换个说法」

> **这一份是【第 20 课】的出题卷。**
> 第 20 课要治的病:现在系统认「平均」这件事,**靠的是一张只认"平均""均值"两个词的词表**
> （`tools/ask.py:1066`）。**换一种说法它就认不出** —— 而"补语言现象永远补不完"。
>
> ★ 所以这一课要把那一层换成 **向量 + 改写**。
> **★★ 而换之前必须先有一把尺子 —— 就是这一份。**

---

## ⚠⚠⚠ 改过一版 —— 第一版量错了,原因记在这

**第一版的尺子报「漏了 2 句(第 7、8 句)」,而那是错的。** 两个错叠在一起:

```
错一:我把「词表认不认得出平均」当成了「系统有没有答错」——
      实测这两句的【去向是"判不出"】,系统【已经出声了】。它是对的。

错二:第 7、8、12、13 句我【没写期次】——
      而系统第一道闸就是"有没有期次",它们【根本没走到"平均"那一层】。
      ★ 我的尺子声称覆盖 14 句,实际只覆盖了 6 句。
```

**★★ 所以这一版的表加了一列「期次写法」,而尺子分成两层量(词表层 / 整条链)。**

## ⚠ 还有一件事:这一份是 AI 起草的

> **出题的人和判卷的人是同一个 → 他永远是对的。**

第一版就是这么翻车的:我把第 13 句标成"档均",**然后拿这个标注去论证"向量比正则准"**。
★ 那不是论证,那是我替用户猜了一个答案,再拿猜的答案当标准。

**★★ 所以标了「★ 要你审」的格子,是真的要你定 —— 不是客气。**

## 这张表在问什么

所有句子**都在问同一个机场**:`上海浦东国际机场`。变的是**问法**和**问的东西**。

「它问的是」那一栏,只能填这六个里的一个:

| 代号 | 含义 | 库里在哪 |
|------|------|---------|
| `档均` | **它所在那个档位**的平均 | `机场分档.行业平均` |
| `得分` | 它自己这期的综合得分 | `综合得分.得分` |
| `档位` | 它属于哪一档 | `机场分档.档位` |
| `排名` | 它这期排第几 | `综合得分排名` 视图 |
| `跨期` | ★ **同一个机场跨几期**的平均 | ⚠ **库里没有这条路** |
| `反问` | ★★ **话本身没说清,该问回去** | — |
| `缺路` | ★★★ **说清了,而库里没有这条路** | — |

**★★★★ 而 `缺路` 这一格，2026-09-23 又被推翻了一层 —— 见下。**

**★★★ 用户 2026-09-23 说「#1 和 #8 我觉得没区别」，并选了答案形态「先给数，再给表」:**

```
我标的:  #1「和同档平均比怎么样」 → `档均`（一个数）
        #8「算是什么水平」      → `缺路`（库里没有这条路）
★ 而真相是:两句要的是【同一个东西】—— 数 + 表

★★★ 所以 #1 看起来"答上了"（它给了【数】那一段），
     #8 看起来"答不了"（它一段都给不了）——
     其实是【同一句话少了一段】:现有系统只会给【数】，【表】那一段根本没有。
```

**★★ 也就是说：「缺路」不是某一句话的毛病，是【这一类答案少了一段】。**
**★ 这比"加一条分支"好办 —— 是给这类答案【补一段】。**

**⚠⚠ 还有一件该记着的：第 1~6 句那个 `档均` 是【AI 自己标的，用户从来没审过】。
用户那句「没区别」可能正是在说那里不对。别把它当已核实的真值用。**

**★★★ `反问` 和 `缺路` 都对用户"出声",但责任方相反（用户 2026-09-23 定的）:**

```
反问  = 「你再说清楚点」        —— 责任在用户，问题被推回去
缺路  = 「我听懂了,但我没有」   —— ★ 责任在这边
★ 用错地方，用户会觉得系统笨 —— 而它其实是懂了的。
```

**★ `反问` 那一栏是这个项目一路的判据:**

```
判不出 = 看得见(反问/拒答)     ← 难看,但不骗人
判错   = 看不见(答得像个样子)   ← ★ 这才是要命的
```

**★★ 而且 `反问` 那一组句子的存在本身是【用户提出来的】** ——
不是我想到的,是审稿时说「这个应该反问,你认为呢?」才补上的。
**★ 而那条意见直接推翻了我拿第 13 句给"向量更准"找的论据(见文末)。**

## ★★★ 三组要分开报,因为代价不一样

```
正向(1~6)  该答「档均」        漏了 = 拒答 = 用户知道没答上来
反问(7,8,13) 该【出声】         ★ 答了 = 静默失败 = 用户看不出来 ← 最要命
反向(9~12,14) 该答【别的】      误判成档均 = 答非所问
```

**⚠ 只看"正向答对几个",会把系统调成一个「什么都答平均」的东西 —— 而它的分数会很好看。**

---

## ★★ 文末:第 13 句为什么从 `档均` 改成了 `反问`

**第一版我标 `档均`,并且拿它当论据:**

> 「向量认为『浦东的平均分是多少』更像【得分】,而正则判成【档均】——
>  ★★ 所以这不是向量更灵活,是**正则会答错、向量答对**。」

**这段论证有两个毛病:**

```
一、「平均分」同样没说【是"什么的平均"】—— 跟第 7 句一个毛病。
   → 按同一条原则,它该【反问】,而不是该答"得分"。
   ★ 而我把"得分"当成了正确答案 —— 那是我替用户猜的。

二、所以那段话根本不是"向量比正则准"的证据,
   是【我先猜了一个答案,再拿猜的答案当标准去量两边】。
   ★★★ 一个自己出题、自己猜答案、自己判卷的论证 —— 它证明不了任何东西。
```

**★★ 而那正是这一课要治的病的一种:不是系统在静默失败,是【我在静默地替用户做决定】。**

**★ 所以我把它改成 `反问`,并留在表里 —— 不是为了难看,是因为它就是这么发现的。**

## ★ 基线（2026-09-23 · 换之前，跑出来的不是估的）

```
词表层（第 20 课要换掉的那一层）      全链层（用户最后拿到什么）
  认得出(正向)      6/6               真答对(正向)      2/6
  没误判(反向)      4/5               反问组出声        3/3
  静默风险(反问组)   1/3
```

**★★★ 正向那 6 句拆开看,才是真相:**

```
✅ 真答对   2 句   1. 上海浦东2025Q4和同档平均比怎么样
                   3. 4000万级以上这个档位2025Q4平均水平是多少
🔇 静默错   1 句   4. 浦东2025Q4所在的档位,大家平均考多少分
                   → 答了「综合得分 4.23,排名第 5/42」★ 答非所问,而看着很正常
❌ 拒答     3 句   2. 5. 6.
```

**★★★ 而词表层对这同一批句子报的是「6/6」。**

```
→ 6 句里【4 句根本没走到那条平均分支】—— 在更前面就被拦下了。
→ 拦它们的是:【机场没认出来】。

    「上海浦东2025Q4和同档平均比怎么样」   → 认得出(「上海浦东」是库名的前缀)
    「浦东2025Q4比同一档的平均高多少」     → 认不出(「浦东」不是前缀)

★★ 库里那个机场叫「上海浦东国际机场」,而人真正会说出口的名字是「浦东」。
★★★ 所以:上游不修,把词表换成向量 —— 这 4 句还是答不出,收益 = 0。
```

**★ 这就是那个排序问题,而它和项目一路的判据一致:「从上游往下游改」。**

## 尺子怎么用

```bash
python tools/说法测试.py            # 第一层:只量【词表】—— 秒出,不用加载模型
python tools/说法测试.py --全链      # 第二层:跑【真的那条链】—— 会调大模型,慢
```

**★ 两层量的是两个不同的东西,别混:**

```

全链层  用户最后【拿到的是什么】   ← 这一层才是用户看得见的
★★ 第一版就是把这两层当成了一个,于是量错了。
```
