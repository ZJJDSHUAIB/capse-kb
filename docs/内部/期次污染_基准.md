## 一、为什么要另立一套基准

期次过滤治的是「**检索到了正确内容,但混进了别的期次**」。
这类题在正式 60 题里**很少**,所以总分动不了 —— 就算改成功了,总分也可能纹丝不动。

**拿总分当证据 = 用一把量不出这个改变的尺子。**

所以另立两个数:

| 指标 | 定义 | 量什么 |
|---|---|---|
| **污染率** | 检索结果里非目标期次的条数 / 总条数 | **过程**:过滤装上了没有 |
| **期次敏感题正确率** | 问句里指名了期次的那些题的得分 | **效果**:用户受益了没有 |

## 三、★ 这个数推翻了"污染率降了 = 做成了"

> ⚠ **本节(3.1~3.3)的逐题表来自【修截断之前】那次冻结,数字已经过时,但结论不变、而且更强。**
> 重冻后的对照是:
> ```
>                   过程指标                    效果指标
> 期次过滤会让      污染率 37% → 0             期次敏感题 9/15 → 最多 11/15
>                   (必然归零,因为就是照着期次删的)   (天花板 +2 道 = +3.3 个点)
> ```
> **一个必然归零的指标,配一个 +2 道的效果 —— 脱钩依然成立。**

### 3.1 两个数只有弱相关(r = +0.337)

**它们是相关的,但远不是同一个东西。** 所以**两个都得报,不能只报一个。**

### 3.2 而且形状是反直觉的

| 污染档 | 题数 | 满分几道 |
|---|---|---|
| **0%** | 6 道(#46 #47 #48 #51 #52 #57) | **0 道 —— 全错** |
| 33% | 3 道(#38 #41 #45) | 2 道 |
| 67% | 6 道(#40 #42 #43 #44 #49 #50) | 2 道 |

**污染率最低的那一批,正确率也最低。**

### 3.3 为什么

**零污染那 6 道,全都是「期次对了、但页码取错了」:**

```
#46 #47 #48  2025Q4-P19 / 2025Q4-P07   ← 期次全对,页全错(要的是 P18/P19/P21)
#51 #52 #57  只有 1~2 条,期次对,页不对
```

**那是另一个病(取错页),期次过滤一点都治不了它。**

→ **如果只看污染率,期次过滤会显示成一次巨大成功(33% → 0),
但它真正能修好的题,可能只有 1~4 道。**

**这就是"过程指标"和"效果指标"脱钩 —— 两个都必须报。**
