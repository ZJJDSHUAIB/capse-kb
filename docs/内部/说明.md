# 内部 —— 这个项目的【过程记录】

> **读代码或跑系统不需要看这里。** 这一目录是开发过程中的台账和实验记录。

---

## 为什么和 `docs/` 分开

**一句话：`docs/` 放「这个系统是什么」，这里放「它是怎么做出来的」。**

对外该讲清的是**它是什么、怎么用、边界在哪**；
而「每一步改了什么、量到了什么」是**过程**，混在项目文档里会淹掉前者。

★ 但过程记录**本身有价值** —— 它是每一个设计决策的来源。所以不是删掉，是收起来。

## ⚠ 有两件事，搬进来的时候踩过

**① 搬文件必须带上「grep 一遍谁在读它」**

2026-09-28 搬 20 个文件时，忘了改三处代码里的路径：

```
tools/agent_指标.py     读 docs/agent指标.json   → 改成 docs/内部/agent指标.json
tools/challenge_run.py  读 docs/_挑战集.json     → 文件名改成了 挑战集.json
tools/make_challenge.py 写 docs/_挑战集.json     → 同上
```

**★ 它们不是搬的时候炸的，是【跑的时候才炸】（`FileNotFoundError`）。**

```bash
grep -rn "文件名" tools/ *.md      # 搬之前先跑这个
```

**② 有几个文件【刻意不放进仓库】**

下面这些在 `.gitignore` 里，**只留本地**：

```
面试素材_*.md  ·  learning-log.md  ·  已知问题分类.md
结论的条件.md  ·  设计文档.md
```

**★ 理由：它们的文件名或开头就在说「这是为面试准备的」。**
**★★ 而这个仓库是给别人看的 —— 那类东西放在里面，反而减分。**
