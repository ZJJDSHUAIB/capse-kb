## ★★★ 而"靶子是错的"这一条，是今天最要紧的发现

第一版的思路是「词表太短 → 换成向量，就能认更多说法」。**量下来不是这样：**

```
「上海浦东2025Q4和同档平均比怎么样」   → 是（就是问档位平均）
「浦东2025Q4跟它那一档的普遍水平比呢」  → ★ 说不清 —— 该反问
「浦东2025Q4综合得分是多少」          → 否

★★ 而现在的 _问的是平均(q) 只返回 True / False —— 【它没有"说不清"这个出口】。
```

**★★★ 所以第 8 句、第 13 句那些毛病，根子不在"词表太短"，
在【这个判据只有两态】。换成向量也一样治不好 —— 除非那一层能说"含糊"。**

**★ 于是这一课的靶子是：不是"认得出更多说法"，是"该说含糊的时候说含糊"。**

这不是猜，是它的接口决定的。**

## 候选量 + 每个量的一句"典型问法"（AI 起草，待审）

**★ 向量要配，就得有东西可配。配的东西是这段——而我起草，你审。**

| 量的名字（库里叫） | 一句典型问法 |
|------------------|------------|
| `档位平均` | 它所在的那个档位的平均分是多少 |
| `综合得分` | 这个机场这一期考了多少分 |
| `档位` | 它属于哪一个档位 |
| `排名` | 它排第几名 |

**⚠ 要你审 / 补的：**

```
① 这四句"典型问法"像不像人说的？★ 我写的是最短最直白的一句 ——
   你要是觉得该写得更口语、或者该多写几句（一个量写两三句），说一声。

② ④ 个量【够不够】？我漏了哪个"人真的会问"的量？
   ★ 比如「样本量」「一级指标数」这种，人会问吗？

③ ★★ 最要紧的：上面那句典型问法，是【我造的】。
   而"用户实际上会怎么问"只有你知道 —— 你身边人会怎么问"它那一档平均多少"？
   想到什么写什么，我一并放进表里。
```

### ★★ 两条路被否掉了，而它们都是我推的

**B 死在哪 —— 它把"用差距判有没有把握"这条路证否了：**

```
✅ 对的: 「和同档平均比怎么样」   top1=档位平均 领先 0.025   ← 差距【很小】但是对的
✅ 对的: 「4000万级以上…平均水平」 top1=档位平均 领先 0.028
❌ 错的: 「这一类机场平均分多少」  top1=综合得分 领先 0.225   ← 差距【极大】但是错的
❌ 错的: 「这季度综合得分是多少」  top1=档位平均 领先 0.001
★★★ 差距和正确性【反着来】—— 不只是重叠。所以"差距小就问、大就用"这条路是死的。
```

**D 死在哪 —— 而它是一条硬证据：**

```
❌「4000万级以上这个档位2025Q4平均水平是多少」→ 字面命中「档位」→ 判"不是在问平均"

★★★★ 这就是「同一个字段有两个身份」，这次出现在【量名】上。
```
